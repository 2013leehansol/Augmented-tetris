# ⚡ 증강 테트리스 VS (Augmented Tetris VS)

클래식 테트리스와 로그라이트 증강(Augment) 시스템의 완벽한 융합!
한 화면에서 펼쳐지는 기상천외한 1대1 라이벌 대전 웹 게임입니다.

🎮 게임 개요

증강 테트리스 VS는 전통적인 테트리스 대전 방식에 현대적인 로그라이트 덱 빌딩(Deck Building) 요소를 결합한 캐주얼 대전 게임입니다.
단순히 블록을 빠르게 쌓고 지우는 것을 넘어, 주기적으로 얻는 특수 증강 능력(Augments)을 조합하여 상대방을 압도하는 나만의 사기적인 빌드를 설계하는 것이 승리의 핵심입니다.

⚔️ 핵심 대전 규칙

1. 라인 공격 및 방어 (Garbage System)

두 줄 이상의 라인을 동시에 클리어하면 상대방의 필드 최하단에 장애물 쓰레기 줄(Garbage Line)이 생성되어 위로 밀어 올립니다.

2줄 클리어: 상대방에게 1줄 전송

3줄 클리어: 상대방에게 2줄 전송

4줄 클리어 (TETRIS!): 상대방에게 4줄의 치명적인 공격 전송

생성되는 쓰레기 줄에는 무작위 위치에 단 하나의 빈 구멍(Hole)이 뚫려 있어, 위기를 극복할 기회를 제공합니다.

2. 실시간 증강 드래프트 (Draft)

각 플레이어는 누적 3줄의 라인을 클리어할 때마다 대전이 일시 중지되며, 무작위로 제시되는 3장의 증강 카드 중 하나를 선택해 장착할 수 있습니다.

증강 카드는 한 게임에서 무제한으로 중첩 장착할 수 있어 후반부로 갈수록 더욱 강력하고 기상천외한 능력이 펼쳐집니다.

🕹️ 플레이어 조작키 (1인용 기기 분할 레이아웃)

본 게임은 하나의 키보드를 나누어 쓰거나 모바일/태블릿 화면을 양옆으로 나누어 플레이하도록 최적화되어 있습니다.

📖 증강 카드 등급 및 상세 가이드

🥇 GOLD TIERS (승리의 열쇠, 게임 체인저)

🛡️ 거울 방패 (Mirror Shield)

효과: 상대방으로부터 유입되는 쓰레기 기물을 $35\%$ 확률로 아예 무효화하고 즉시 반사합니다.

암기: "받사! 35% 즉시 역공"

💀 미다스의 공포 (Midas Terror)

효과: 라인을 제거하여 공격을 보낼 때 상대방에게 항시 +1줄의 보너스 공격을 더 가합니다.

암기: "공격할 때 무조건 +1줄"

👾 나노 블록 (Nano Blocks)

효과: $15\%$ 확률로 1칸짜리 점(Dot) 또는 2칸짜리 초소형 사기 블록이 대기열에 등장합니다.

암기: "구멍 땜빵용 미세블록"

❤️ 비상 보호막 (Emergency Shield)

효과: 블록이 맨 위로 꽉 차서 게임오버가 되기 직전, 하단 6줄을 일시 소멸시키며 기사회생합니다. (판당 1회 제한)

암기: "목숨 코인 +1 (일회용)"

🥈 SILVER TIERS (특수 전술 및 피지컬 강화)

🌊 지진 충격파 (Seismic Waves)

효과: 하드 드롭 시 공중에 붕 떠서 비어있는 구멍들을 중력의 힘으로 강제 정렬하여 아래로 압축합니다.

암기: "스페이스바/엔터 = 빈칸 압축"

🔥 콤보 폭격기 (Combo Bomber)

효과: 연속으로 라인을 제거하는 콤보가 유지될 경우, 매 콤보마다 추가 공격 1줄을 얹어 전송합니다.

암기: "콤보 이어질 때 추가 폭탄"

💣 화약 전문가 (Demolitionist)

효과: 5번째 낙하하는 블록이 착지하면 주변 $3 \times 3$ 영역을 완전히 폭파시키는 분홍색 폭탄 블록으로 낙하합니다.

암기: "5번째마다 핑크폭탄 착지"

🥉 BRONZE TIERS (패시브 및 유틸리티 변수)

↕️ 일자형의 축복 (Blessing of I)

효과: 테트리스의 구원자, 일자형 막대(I-Tetrimino)의 등장 확률이 $50\%$ 가량 대폭 상승합니다.

암기: "일자막대 50% 폭증"

🔄 차원 변환기 (Dimension Warp)

효과: 홀드 키 입력 시 이미 홀드가 가득 찬 상태라면, 현재 기물을 무작위 새 기물로 강제 교체합니다. (재사용 대기시간 10초)

암기: "망한 블록 강제 리롤(Reroll)"

🏆 추천 필승 증강 시너지 조합

지진 충격파(🥈) + 콤보 폭격기(🥈)

운영: 블록을 높게 쌓아 대충 배치해도 하드 드롭만 하면 바닥으로 압축 정렬됩니다. 정렬되면서 자연스럽게 터지는 무작위 폭격 연쇄 라인 클리어로 고효율 공격을 연속해서 가할 수 있습니다.

미다스의 공포(🥇) + 일자형의 축복(🥉)

운영: 가장 정석적이고 무서운 폭딜 트리입니다. 일자 막대를 빠르게 소환하여 테트리스(4줄 제거)를 연달아 터트리며 미다스 보너스를 얹어 단숨에 상대를 질식하게 만듭니다.

거울 방패(🥇) + 비상 보호막(🥇)

운영: 극단적인 존버(수비형) 빌드입니다. 쉴드로 받아치고, 꽉 차서 위태로울 때 보호막으로 6줄을 날려 버티며 상대방의 자멸을 유도합니다.

🛠️ 기술 스택 및 개발 정보

Language: Vanilla JavaScript (ES6+)

Styling: Tailwind CSS & Font Awesome (네온 사이버펑크 테마)

Graphics: HTML5 Dual Canvas (독립적 물리 엔진 탑재로 주소 참조 중복 버그 완전 해결)

Optimization: 60FPS 최적화 애니메이션 루프 제어 기능 적용
